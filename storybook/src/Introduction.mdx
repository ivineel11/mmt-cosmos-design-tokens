# Cosmos

Cosmos is the MakeMyTrip design system. One Tokens Studio file, `tokens/tokens.json`, is compiled by Style Dictionary into CSS, TypeScript, Swift and Kotlin. Everything in this Storybook reads those generated files, so what you see here is what ships.

## Three tiers

| Tier | What it holds | Who uses it |
|------|---------------|-------------|
| **Primitives** | Raw values: hex colours, pixel sizes, the Lato and Rubik families | Token authors only |
| **Semantic** | Role names that describe intent, such as `text-primary` and `bg-fill-brand` | Product code and Figma |
| **Component** | One key per property, variant and state, such as `button/bg-primary-hover` | Cosmos components and their Figma variable bindings |

Each tier only references the tier below it. Product code uses semantic tokens; components use their own component tokens.

## How to read this Storybook

- **Foundations** explains each visual layer (colour, type, space, shape, elevation, opacity) with live specimens.
- **Tokens** lists every token in each tier. Search by name, value, alias or description, and switch between CSS, JS, Swift and Kotlin names. Click a name to copy it.
- **Components** has a live React component for each Figma component set, with every Figma variant axis as a control. Available now: Button, Badge, Switch, Checkbox, Radio, Chip, Chip / Vertical, Tabs, Segmented control, Slider, List, Menu, Snackbar and Tooltip. Top app bar follows.

## Using the tokens on web

```css
/* dist/web/tokens.css from this repository, loaded once */

.card {
  background: var(--color-bg-surface-secondary);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-card);
  padding: var(--space-md);
}
```

Load the fonts of the brands you serve yourself: Lato 400, 700 and 900, and Rubik 400, 600 and 700 for Goibibo. The token package does not ship font files.
