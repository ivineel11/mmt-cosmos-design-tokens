# Elevation

Cosmos has one elevation scale, written as shadows and named by what sits at each height. Every shadow has two layers: a tight **key** layer that defines the edge and a soft **ambient** layer that carries the height. There is no spread and no inner shadow, because SwiftUI and Compose cannot draw them, so the three platforms match.

A shadow only ever means height. The edge of a card stays a `border-*` token.
