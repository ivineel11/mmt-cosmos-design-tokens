# CLAUDE.md

MakeMyTrip Cosmos design tokens: one Tokens Studio JSON source compiled by Style Dictionary into web, iOS and Android code. `README.md` is the full reference (taxonomy, inventory, mappings, design decisions). Read the relevant section before adding or renaming tokens.

## Commands

```bash
npm install && npm run build:tokens     # regenerate dist/ from tokens/tokens.json
node scripts/describe-primitives.mjs    # recompute primitive colour descriptions (contrast ratios)
cd docs-site && npm install && npm run dev   # docs site; needs build:tokens to have run first
```

There are no tests or linter. The build is the check: it resolves every reference and runs the opacity validator. A clean run followed by a `git diff` of `dist/` is how you verify a change.

## Layout

- `tokens/tokens.json`: the only source of truth. Three sets: `primitives` → `semantic` → `component`.
- `build-tokens.mjs`: Style Dictionary config and custom `mmt/*` transforms.
- `dist/`: generated output, committed. Never edit it by hand.
- `components/*.md`: component specs generated by the `create-component-md` skill from Figma.
- `proposals/`: design rationale for token changes. `docs-site/`: a Next.js reference site with its own README.

## Rules that matter

- **Tiers only reference the tier below.** Semantic tokens alias primitives, and component tokens alias semantic tokens. No raw hex outside `primitives`, and no component token pointing at a primitive.
- **Every semantic and component token needs a `description`** that states intent and boundary (which neighbouring token to use instead) and not the value. Descriptions sync to Figma, so **don't use apostrophes** in them, because Figma HTML-escapes them.
- Opacity is a decimal from 0 to 1 in JSON (Figma holds the percentage). Every `opacityScale` step needs an `opacity.*` mirror, and the build throws otherwise.
- Keep `$metadata.tokenSetOrder` as `["primitives", "semantic", "component"]`.
- Name semantic tokens by role (`text-caution`), not by value (`text-yellow-700`).
- After changing a primitive colour, re-run `describe-primitives.mjs` so the quoted contrast ratios stay correct.
- When a token's name, value or count changes, update the matching README inventory and mapping tables in the same commit.

## Committing

Commit `tokens/tokens.json` and the regenerated `dist/` together. Commit subjects are imperative sentences in sentence case that describe the outcome, for example "Add bg-secondary and pair canvases with containers by suffix".
